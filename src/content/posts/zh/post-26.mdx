# 1. 为什么对 Agent 感兴趣

对 Agent 持续感兴趣，最直接的原因来自于独立开发的需求。传统开发中，一个人的时间和精力终究有限，产出量和覆盖范围存在上限。但如果有 Agent 协同，不仅能大幅增强现有工作的效能与质量，还能借助智能体团队突破开发环节的能力与资源限制，独立支撑产品全生命周期的运转。这种杠杆效应，对于时间资源宝贵的独立开发者而言具有巨大的吸引力。

另一个感兴趣的点是 Agent 带来的计算机架构范式演化和人机协作范式演化可能蕴含巨大潜能。计算机行业发展至今几十年带来了巨大的生产力飞跃，而这一切都是基于 CPU 和冯诺依曼架构，其特点是以**算力**为核心工具形态提供服务，人在人机协作中被作为**挂载设备**为其提供智能和环境交互；而如今 Agent 范式下计算机是以**智能**为核心对外提供服务也兼具更丰富的环境感知和操作，它不再以工具形态而是更类似于智能体生物，人机交互范式中的人不再需要像挂载设备，他可以以人的自然交互和类智能体互补合作，协同进化。智能体可能代替了之前模式中人的部分工作，但换个角度看人之前作为工具角度价值在弱化，人的存在性和独特性才是真正的价值。这一切正在发生，要理解和适应这一切学习和使用 Agent 范式是个好的开始。

# 2. 为什么用 Hermes Bots

几个月前就想用 OpenClaw 做一些事情，当时各大媒体宣传其无所不能，但我最基本的日常新闻都不够稳定，换了模型后有所提升但是依然稳定性不高，加上每次版本升级基本要手动修复很久，最终感觉得不偿失慢慢就放弃了。搁置几个月看了些评论发现之前热度有点过于高，原来真实使用下大家其实感受都一样并不是自己菜。

Hermes 当时热度肯定没有 OpenClaw 高的，而且看主页感觉个性化比较强有点小众。然而几个月下来证明它确实更加出色：
- 首先是功能和版本的稳定性，这个其实非常重要。
- 其次是更好的自学习系统。我觉得差异可能来自于设计理念，类似 Claude Code 产品可能设计是编码工具，所以很多记忆和存储需要使用者主动发起。而 Hermes 设计更像一个生命体，自我学习成长。Claude Code 作为编码辅助其实很出色，但虚拟团队来说，Hermes 机制更符合场景。
- 最后是省token。OpenClaw 比较烧 token，得益于提示词缓存机制，Hermes 在这方面会好很多。

近期 Hermes 还新增了 Bots 模式，使得每个 Agent 上下文会更精简，Skill 设计也可以更专业，从效率准确度以及费用来说，使用 Hermes Bots 更适合构建 Agent 团队。

# 3. 为什么用中土世界背景的 Agent 团队
托尔金笔下的《指环王》构建了宏大史诗般、复杂而完整的世界。黑客历史上就有使用中土地名的传统——早在 20 世纪 60 年代末，加州斯坦福人工智能实验室（SAIL）的黑客们就把服务器机房命名为“魔多（Mordor）”、休息室命名为“跃马客栈（The Prancing Pony）”；后来的硅谷公司 Palantir 亦是如此。而其中鲜明的人物性格，如今也非常适合作为 Agent 的人设与团队隐喻。

# 5. 配置的 TIPS
- 性能优化
  - 精简 skill & tools: 创建多个 Bots 以后，会明显感觉到切换卡顿加载，精简每个 bot 的 skill 和 tools 后，能大幅度改善加载性能。
  - 多路复用网关：参考[multi-profile-gateways](https://hermes-agent.ac.cn/docs/user-guide/multi-profile-gateways) 只需要加一个配置，就可以让多个 bots 用一个网关，降低运行和维护成本。
- 飞书渠道配置
  - bot 1:1 配置飞书应用: 比起只配置 1 个飞书应用转发内容给内部 bots，多个 bots 虽然配置麻烦点，但在消息处理速度，独立性，和易用性更好。<img src="/images/posts/26/5.webp" class="w-2/3" />
  - 聊天群：飞书支持一个群加入多个机器人，可以通过 @ 唤起发送对应内容。和 Hermes 桌面端不同在于 bots 无法获取群里广播消息，从性能和开销看能接受。

# 6. 后续的工作

## 持续的调优
和传统意义上软件的发布及交付完整功能不同，Agent 配置后不是结束而是一个开始，和日复一日生活一样，不断迭代才是智力和能力之源，需要大量数据调优以及结合生活和工作的持续对话和验证才能发挥威力。
为每一位 Agent 持续打磨更好的 soul 和skill，这有点像DND游戏，可以搭配不同角色，每个角色搭配不同技能，最终构建更好的组合完成冒险任务。
以 Agent 为载体记录知识，也比纯文字笔记更有用。

## 关心生活和工作
Agent 团队并不是真人，它其实是个人思维和能力的投影，只有自己更加理解工作和生活，具备更清晰的世界观人生观和价值观，才能赋予他们更有效的能力和灵魂。
